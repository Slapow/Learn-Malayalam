# Persistent Antigravity Agent Rules

## Execution Constraints (Strict)
- DO NOT run `./gradlew` or `gradlew.bat` in the terminal or in background processes.
- DO NOT execute unit tests (`testDebugUnitTest`), build configurations, or background verification tasks.
- DO NOT execute PowerShell pipeline search commands (such as `Get-ChildItem | Select-String`). Inspect files via direct file paths or internal IDE project context.
- Apply all code modifications, refactors, and schema changes directly to the source files.
