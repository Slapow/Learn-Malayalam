# Parayu Malayalam — Android APK Installer

This folder contains the pre-built Android application package (`parayu-malayalam.apk`) ready to install on your phone (e.g., Samsung Galaxy S25).

## How to Install / Update on Your Galaxy S25

1. Open this repository on your phone's browser (or download `parayu-malayalam.apk` on your computer and transfer it to your phone).
2. Tap **`parayu-malayalam.apk`** and select **Download** (or **View raw** to download the file).
3. Open the downloaded `.apk` file from your phone's **Notifications** or **My Files > Downloads**.
4. Tap **Update** (if already installed) or **Install**.
5. Your learning progress, XP, and streaks are synced with **Cloud Firestore** and will remain intact.
